Car Detailing Workshop Management System is a full-stack web application designed to digitize and simplify the complete vehicle servicing and repair process. The platform connects customers, workshop managers, service advisors, mechanics, and administrators through a role-based system, providing an efficient workflow from vehicle registration and appointment booking to repair tracking, payment, invoicing, communication, and sales analytics.

Customers can create an account, verify their email, manage their profile, add multiple vehicles, and upload vehicle images using Cloudinary. They can explore available automotive services, view service details and estimated pricing, find suitable workshops, check workshop availability, select required services, choose an appointment date and time slot, and receive an estimated repair cost before booking. Customers can also make the required initial payment and receive confirmation notifications and emails.

After an appointment is created, the selected workshop receives a notification. The workshop manager can manage services, employees, inventory, and workshop operations. Once the customer's initial payment has been completed, the workshop manager can assign the repair work to an available mechanic belonging to that particular workshop. This ensures that work is assigned only after the required initial payment has been received.

Mechanics can view their assigned repair jobs and the services that need to be performed on each vehicle. The repair workflow allows the progress of a vehicle to be tracked through different stages. Only the authorized workshop manager can update the repair progress, maintaining proper control over the workshop's operational workflow. Customers can monitor the progress of their vehicles and receive updates whenever the repair status changes.

The system also includes a community communication feature that allows customers and service advisors to communicate regarding an appointment. Service advisors can send text messages and vehicle-related images to customers, while customers can access their conversations through the Community section of their profile. Uploaded images are stored securely using Cloudinary, and conversation history is maintained for future reference.

Payment and billing are integrated into the appointment workflow. Customers can complete the initial payment before work is assigned to a mechanic, while the system maintains the estimated service cost and final repair information. After the repair is completed, an invoice is generated containing customer, vehicle, workshop, service, payment, and appointment details. Customers can view and download their invoices.

Workshop managers can also manage workshop inventory and employees, ensuring that workshop resources are organized according to operational requirements. Workshop-specific access restrictions prevent a manager from modifying another workshop's employees, inventory, services, appointments, or repair operations.

The administrator has system-wide access and can manage workshops, users, services, and other major platform operations. The application also provides sales analytics for both administrators and workshop managers. Administrators can view overall sales information across workshops, while workshop managers can view sales data related only to their own workshop. Analytics include appointment statistics, completed repairs, collected revenue, estimated revenue, monthly sales information, and workshop-specific performance data.

The application uses role-based authentication and authorization to provide different dashboards and permissions for customers, mechanics, service advisors, workshop managers, and administrators. JWT-based authentication protects API requests, while OTP-based verification is used for account and profile-related security operations. Email notifications are handled through Nodemailer.

The frontend is built using React with Vite and Tailwind CSS, providing a modern, responsive interface optimized for desktop, laptop, tablet, and mobile devices. React Router is used for navigation and role-specific dashboard routing. The backend is built with Node.js and Express.js, with MongoDB and Mongoose used for database management. Cloudinary handles vehicle and repair image storage, Multer manages file uploads, Nodemailer handles email communication, and PDF generation is used for downloadable invoices.

Overall, the system provides an end-to-end digital workshop management solution that connects customers with automotive workshops while managing appointments, vehicles, services, payments, mechanic assignments, repair progress, communication, inventory, employees, invoices, notifications, and business analytics within a single platform.
